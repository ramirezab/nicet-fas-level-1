# NICET FAS Simulator

Study site for the **NICET Fire Alarm Systems Level I, II and III** exams (content outlines updated March 25, 2024; NFPA 72-2022, NFPA 70-2020, IBC-2021, NFPA 101-2021).

- Timed practice exams in the real format and weighted like each official content outline (Level I: 85 questions / 110 min · Level II: 110 / 155 · Level III: 115 / 170)
- Question banks by chapter and by outline task, each question with an explanation and code reference
- Study guides, tab lists and a glossary written for taking the exam with printed, tabbed code books

Progress is saved in each visitor's own browser (localStorage).

All questions are original. Real NICET exam items and NICET's practice tests are confidential or copyrighted and are not reproduced. Not affiliated with or endorsed by NICET or NFPA.
