# NICET FAS Level I Simulator

Study site for the **NICET Fire Alarm Systems Level I** exam (content outline effective March 25, 2024; references NFPA 72-2022, NFPA 70-2020, Ugly's 2020).

- Timed 85-question practice exams weighted like the official outline (42 Installation / 38 Maintenance / 5 Submittal & Layout)
- 552 original questions by chapter and by outline task, each with an explanation and code reference
- Study guides written for taking the exam with printed, tabbed code books

Progress is saved in each visitor's own browser (localStorage).

All questions are original. Real NICET exam items are confidential and are not reproduced here. Not affiliated with or endorsed by NICET or NFPA.
